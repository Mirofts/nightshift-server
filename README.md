# Night Shift - online server

This is the matchmaking server used by EVERY copy of the game (CrazyGames, itch.io, Poki, PC, Mac, iPhone, Android, tablets).
- Rooms of 6 players; if nobody else shows up within 6 seconds, the empty seats are filled with bots.
- Check it is alive: open https://YOUR-ADDRESS.onrender.com/health
- Deploy: Render.com -> New -> Blueprint -> pick this GitHub repository (render.yaml does the rest).
